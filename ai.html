AI that knows the project.

UAssist connects to the providers you choose, gives the assistant a grounded view of your cards and assets, and lets you turn conversation into work.

Bring your own model

UAssist does not bundle a language model. You configure one or more providers in the AI settings panel. Supported options include local models through Ollama or LM Studio, and remote providers like OpenAI, Anthropic, or any OpenAI-compatible endpoint.

Each provider has its own API key, endpoint, default model, and spending cap. You can assign different providers to chat and agent tasks, or keep everything local.

Start local. UAssist works fine with a small local model for planning and discussion. Agents are usually better with a stronger model, so you can route them separately.

Context from the project, not from memory

When you chat with the assistant inside UAssist, it does not rely on a long conversation history. It reads the current project state:

  • The active board and selected view.
  • The card or document you are currently looking at.
  • Anchored file paths and whether they exist.
  • Open health items and recent job results.
  • Project conventions saved from earlier agent jobs.

This means you can ask “what is blocking the turret card?” and get an answer based on the actual board. You can ask “split this card into smaller tasks” and the assistant will propose real cards with proper anchors.

Chat that creates tasks

Every card and every document has a chat thread. The chat is not a side feature. It is a way to edit the project.

  • Discuss a card. Ask why it is blocked, what the acceptance criteria mean, or how to verify it.
  • Rewrite a card. Tell the assistant the description is unclear and ask for a better one.
  • Create cards. Describe a new feature and let the assistant propose a card with anchors and a milestone.
  • Write docs. Ask the assistant to expand an architecture note from a chat message.

Clarity beats cleverness. The chat is useful because it is grounded. A generic chatbot guesses. UAssist knows what you are looking at.

Privacy by design

Your project files stay on your machine. If you use a local model, nothing leaves your machine at all. If you use a remote provider, only the context you explicitly send goes out. UAssist does not phone home.

You set cost caps per provider. The assistant cannot rack up charges because the server stops it at the limit.
