Asteroid Run

A field report on building a small scrolling shooter with UAssist, Unity, and Blender. From one sentence in a Markdown file to a playable build in five evenings.

What this is

The book walks the whole project in ten short chapters. Each chapter covers one phase of the build and the exact UAssist workflow used: plan import, anchors, agent dispatch, health validators, and export.

Chapters

  1. Preface — the tools and the premise.
  2. The idea in one sentence — writing the design contract.
  3. Phase 0: foundation — init UAssist and import the plan.
  4. Phase 1: the ship and the camera — first agent dispatch.
  5. Phase 2: rocks that never end — multiple anchors and Blender scripts.
  6. Phase 3: enemies with behavior — blocking cards and socketed models.
  7. Phase 4: weapons and targeting — prefabs, HUD, and health validators.
  8. Phase 5: feel and juice — particles, audio, and licence tracking.
  9. Phase 6: the loop — title screen, HUD, and high scores.
  10. Shipping it — export and generated credits.
  11. What I learned — why anchored work matters.
