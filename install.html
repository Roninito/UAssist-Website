Install UAssist

UAssist runs locally with Bun and serves its own web UI. Nothing leaves your machine unless you choose an external AI provider.

What you need

  • Bun 1.3+ — bun --version should print a version.
  • Unity and optionally Blender for the projects you want to coordinate.
  • Git — agents use isolated worktrees.
  • (Optional) Ollama or LM Studio for local AI chat.

Clone and install

git clone https://github.com/RastaCamp/uassist.git
cd uassist
bun install

Run bun test to verify everything is wired correctly before you start real work.

Start and stop the server

The server is one Bun process. It hosts the REST API, WebSocket, and web UI.

bun run start     # run once
bun run dev       # run with --watch

The default port is 7373. Open http://127.0.0.1:7373 in your browser.

To stop, press Ctrl-C in the terminal.

Load a project

UAssist state lives inside your target project’s .uassist/ directory. From that project root:

uassist init
uassist plan import design/plan.md
uassist serve       # opens http://127.0.0.1:7373 automatically

If uassist is not on your path yet, use bun run packages/cli/src/uassist.ts from the UAssist repo.

Add to dock or desktop

macOS

Create a small AppleScript wrapper and save it as an app with Script Editor:

do shell script "cd /path/to/uassist && bun run start"

Save as Application, then drag it to the Dock. Or use a launcher like Raycast with a shell command alias.

Linux

Create a .desktop entry:

[Desktop Entry]
Name=UAssist
Exec=bun run --cwd /path/to/uassist start
Type=Application
Terminal=true

Place it in ~/.local/share/applications/. It will show up in your launcher.

Windows

Create a batch file and pin it to the taskbar or Start menu:

@echo off
cd /d C:\path\to\uassist
bun run start

For a nicer shortcut, create a .lnk pointing to the batch file and pin it.

Update UAssist

UAssist is a git repo. Updating is one command:

cd /path/to/uassist
git pull origin main
bun install

Your projects are safe. UAssist state lives inside each target project’s .uassist/ folder, not inside the UAssist install directory.
